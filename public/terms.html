1. What CIMI is

CIMI aggregates reputation data from public threat-intelligence services and blends it into a single verdict per indicator. It is a decision-support tool for security analysts. It is not a substitute for investigation, and a verdict is not proof that a host, file or address is malicious or safe.

When no API keys are configured, results come from an offline simulator and are labelled "simulated"; they are deterministic test data and carry no intelligence value.
